# Sprint 9 — Visualización y storytelling

Análisis de datos de transacciones mediante Python y MySQL, desarrollado en un Jupyter Notebook desde Visual Studio Code.

## Objetivo

Crear visualizaciones e interpretar sus resultados para identificar patrones de venta, riesgos y oportunidades de negocio.

## Contenido

- **Nivel 1:** análisis de transacciones, usuarios, importes, productos y patrones temporales. Comparación de visualizaciones propias con alternativas propuestas por IA.
- **Nivel 2:** análisis de productos y captación de nuevos usuarios, y estudio de las compras locales e internacionales.
- **Nivel 3:** mini-dashboard para el departamento de Ventas / Comercial e informe ejecutivo en dos versiones: sin IA y con apoyo de IA.

## Herramientas

Python, Pandas, Matplotlib, Seaborn, SQLAlchemy, MySQL y Visual Studio Code.

## Cuaderno

[Consultar Sprint_9.ipynb](./Sprint_9.ipynb)

El cuaderno contiene los enunciados, el código, las visualizaciones y las interpretaciones de los resultados.

Para volver a ejecutarlo, se necesita acceso a la base de datos MySQL `sprint2_estrella` y configurar la conexión correspondiente.
